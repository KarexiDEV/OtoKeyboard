# Changelog
All notable changes to this project will be documented in this file.

## [v1.2.2]
### Notes
- The application is now completely free.
- Added active user count statistics.
- Resolved some identified bugs.

## [v1.2.1]
### Notes
- Fixed underlying infrastructure-related issues.
- Resolved identified bugs that caused the application to close unexpectedly.
- Implemented security-focused improvements and adjustments.

## [v1.2.0]
### Notes
- Added new language support: Spanish, French, German, and Portuguese.
- Fixed critical bugs that caused the program to crash unexpectedly.
- Addressed and fixed various reported bugs.
- Added a license expiration warning for licensed users.
- Implemented settings "Import/Export" feature for licensed users.

## [v1.1.9]
### Notes
- Added a "wait for hotkey" feature: {wait_for_hotkey}
- Redesigned the HUD for a cleaner and more modern user experience.
- Implemented width and height limitations for the HUD.
- Redesigned the "Add/Delete Profile" buttons for better clarity.
- Added a "Reset Settings" button to the Settings menu for a fresh start.
- Integrated new help buttons to guide you.
- The underlying update functions have been improved.
- This update is all about giving you more control and a smoother experience. ✨
- Stay tuned, the next features might surprise you!
- If you have any issues with the update, please report them to us at https://www.reddit.com/r/OtoKeyboard/ or via email at support@otokeyboard.com.
